# Login Page - Manual Test Cases

## TC_001 - Valid Login
1. Open the login page.
2. Enter a valid username and password.
3. Click Login.
Expected Result: User should successfully log in.

## TC_002 - Invalid Password
1. Enter a valid username.
2. Enter an incorrect password.
3. Click Login.
Expected Result: An appropriate error message should be displayed.

## TC_003 - Empty Username
1. Leave the username field empty.
2. Enter a valid password.
3. Click Login.
Expected Result: Username validation message should be displayed.

## TC_004 - Empty Password
1. Enter a valid username.
2. Leave the password field empty.
3. Click Login.
Expected Result: Password validation message should be displayed.

## TC_005 - Invalid Email Format
1. Enter an invalid email format.
2. Enter a password.
3. Click Login.
Expected Result: Email validation message should be displayed.
